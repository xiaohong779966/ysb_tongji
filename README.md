# 2026年中秋、国庆值班安排表

一个单文件网页，用于统计 2026 年中秋节、国庆节假期的值班人员安排。每天最多 3 人。

## 怎么用

双击 `index.html` 用浏览器打开即可（无需联网、无需安装任何东西）。

1. 在某个日期后面输入姓名，点「添加」或按回车；
2. 某天排满 3 人后，该日期不再显示输入框，并提示「已满3人」；
3. 点姓名后面的 `×` 可以删除（有二次确认）；
4. 下方「人员值班天数统计」自动汇总每个人的值班天数和具体日期；
5. 排好后用「导出表格（Excel）」生成 CSV，或「打印 / 存为PDF」出纸质版/PDF。

## 值班日期（依据国务院正式通知）

依据《国务院办公厅关于2026年部分节假日安排的通知》（**国办发明电〔2025〕7号**，2025-11-04 发布）：

| 节日 | 放假日期 | 天数 | 说明 |
| --- | --- | --- | --- |
| 中秋节 | 9月25日（周五）— 9月27日（周日） | 3 天 | 与周末连休，无需调休 |
| 国庆节 | 10月1日（周四）— 10月7日（周三） | 7 天 | 调休上班：9月20日（周日）、10月10日（周六） |

合计 10 个值班日，满编 30 个班次。
来源：https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm

## 数据存在哪

- 数据保存在**本机浏览器**的 localStorage（键名 `duty-2026-zhongqiu-guooing`），刷新、关掉浏览器再打开都还在。
- 换电脑、换浏览器或清理浏览器数据后会丢失，重要安排请用「备份数据」导出 JSON 保存，需要时用「恢复备份」导入。
- 「导出表格（Excel）」的 CSV 只用于查看/打印，不用于恢复；恢复请用 JSON 备份。

## 想改日期怎么办

打开 `index.html`，找到脚本最上面的 `GROUPS` 配置（有注释标注），按同样格式增删日期即可；
每天的人数上限改 `MAX_PER_DAY` 变量（当前为 3）。
